## 📋 Customer Management System with SQLite
Project developed in Python to simulate a customer management system using SQLite as a local database.

## 🚀 Features
✅ Add new customers
✅ List all registered customers
✅ Update customer information
- Full customer data update
- Update specific fields only
✅ Delete customers by ID
✅ Persistent data storage using SQLite

## 🛠️ Technologies Used
- Python 3
- SQLite3

## 📂 Project Structure
**CREATE:** Register new customers
**READ:** View and list customers
**UPDATE:** Update customer information
**DELETE:** Remove customers

## 💾 Database
Data is stored locally in an SQLite database, eliminating the need to install a database server.

## 🎯 Concepts Practiced
- SQLite database management
- CRUD operations
- SQL (INSERT, SELECT, UPDATE and DELETE)
- Data manipulation with Python
- Loops and conditional statements
- Usage of fetchall() and fetchone()
